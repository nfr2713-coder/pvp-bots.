# PvP Боты (Fabric, Minecraft 1.21.11)

Клиентский мод. Меню — клавиша **G** (меняется в настройках управления).

## Сборка
Проще всего: сгенерируйте пустой шаблон на https://fabricmc.net/develop (Minecraft 1.21.11, Yarn, Fabric API),
скопируйте в него папку `src/` из этого архива (и `fabric.mod.json` проверьте на совпадение id), затем:

    ./gradlew build

Готовый файл: `build/libs/pvp-bots-1.0.0.jar` (не `-sources`). Положите в `mods/`.
Либо используйте мои build.gradle/gradle.properties, подставив актуальные версии с fabricmc.net/develop.
Требуется JDK 21.

## Что есть
- боты существуют только в клиентском мире, на сервер от них ничего не уходит
- удар/ПКМ по боту перехватываются и не отправляются серверу
- русское меню: создание/удаление, имя, скин (18 стандартных), координаты и измерение, ТП бота,
  «Бот ко мне», поведение (стоять / следовать / кружить), редактор комплекта, настройки
- «Тянуть меня к боту» со скоростью 1–500 блоков/сек (в одном измерении)
- удар булавой по боту подбрасывает вас вверх (сила настраивается)
- бот сохраняется и появляется, когда вы заходите в его измерение

## Известные ограничения
- Скины: только стандартные (Steve/Alex и т.п.), скин по нику игрока не реализован.
- Притяжение и подброс двигают ВАШЕГО игрока обычными пакетами движения. Сервер может откатывать
  позицию (особенно при скорости больше ~100 блоков/сек) и может банить античитом. Используйте на свой риск.
- Падение после подброса на сервере наносит обычный урон от падения.
- Код написан без возможности скомпилировать, названия методов 1.21.11 могут потребовать правок.
